Frankot–Chellappa Algorithm (MATLAB Implementation)

This page documents a MATLAB implementation of the Frankot–Chellappa algorithm, originally proposed in:

Frankot, R. T., & Chellappa, R. (1988). "A Method for Enforcing Integrability in Shape from Shading Algorithms". IEEE Transactions on Pattern Analysis and Machine Intelligence.

1. Mathematical Background

Given a gradient field (px, py), the goal is to recover a surface φ(x,y). The method enforces integrability in the Fourier domain using:

Φ(ωx,ωy) = (-iωx Px - iωy Py) / (ωx² + ωy²)

2. MATLAB Implementation

function phi = frankot_chellappa(px,py) [M,N] = size(px); [wx,wy] = meshgrid( ... (-N/2:N/2-1)*(2*pi/N), ... (-M/2:M/2-1)*(2*pi/M)); Px = fftshift(fft2(px)); Py = fftshift(fft2(py)); den = wx.^2 + wy.^2; den(den==0) = 1; Phi = (-1i*wx.*Px - 1i*wy.*Py)./den; Phi(den==0) = 0; phi = real(ifft2(ifftshift(Phi))); end

3. Description

  • Transforms gradients into Fourier domain
  • Applies integrability constraint
  • Reconstructs surface via inverse FFT

4. Notes

This implementation is a direct discretization of the original formulation proposed by Frankot and Chellappa (1988).
